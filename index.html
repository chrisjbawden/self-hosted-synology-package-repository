How to Add This Repository

Follow these steps to add the repository to your Synology NAS.

  1. Open Package Centre Sign in to your Synology DSM interface and launch Package Centre.
  2. Open Settings Click the Settings button within Package Centre.
  3. Select Package Sources Navigate to the Package Sources tab and click Add.
  4. Add the Repository Enter a name such as "Chris Bawden Packages" and paste the repository URL above.
  5. Save and Browse Click OK to save the repository. Available packages should appear under the Community section.
